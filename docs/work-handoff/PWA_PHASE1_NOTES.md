# QuranOS PWA — Phase 1

هذه المرحلة تضيف أساس نسخة الهاتف القابلة للتثبيت دون تغيير قاعدة البيانات أو Supabase أو منطق الأعمال.

## النطاق

- Web App Manifest عربي RTL باسم QuranOS.
- أيقونة تطبيق عادية وأيقونة Maskable.
- Service Worker على نفس أصل التطبيق فقط.
- لا يعترض إلا طلبات GET؛ لا يتعامل مع Supabase/Auth أو عمليات الكتابة.
- Navigation يعمل Network First مع fallback إلى App Shell عند انقطاع الشبكة.
- أصول الواجهة المحلية يمكن تخزينها Runtime Cache بعد زيارتها.
- تسجيل Service Worker من نقطة دخول React.
- اختبارات ثابتة لقابلية التثبيت وحدود التخزين المؤقت.

## خارج النطاق في هذه المرحلة

- Push Notifications.
- تنبيه غياب الطالب.
- تخزين اشتراكات أجهزة الأولياء.
- أي Migration أو Edge Function جديدة.
- APK/AAB أو تطبيق Native مستقل.

## المرحلة التالية المقترحة

بعد التحقق من تثبيت PWA على جهاز Android فعلي، يضاف نظام Notifications في PR مستقل. عندها يمكن بناء تنبيه الغياب بحيث يصدر بعد اعتماد الغياب/انتهاء مهلة الحضور، مع idempotency ومنع التكرار وسجل إرسال قابل للتدقيق.
