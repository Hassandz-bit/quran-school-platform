## الأمان والصلاحيات

- `academic_supervisor` يملك `attendance.view` فقط ولا يملك `attendance.manage`.
- `school_admin` و`branch_manager` و`teacher` يملكون الإدارة ضمن نطاقهم؛ المعلم مقيد بملفه وتعييناته النشطة.
- لا وصول لـ`anon`، ولا `service_role`، ولا مفاتيح ثابتة، ولا حذف مباشر.
- لا `select("*")`.
- الكتابة تعيد فحص `attendance.manage` ثم تتحقق منها RLS وTriggers.
- دالة `can_access_attendance_class` من نوع `SECURITY DEFINER` مقصودة؛ تعيد Boolean فقط، تتحقق من العضوية والنطاق، تضبط `search_path = ''`، ولا تُمنح لـ`anon`.
- قراءة أسماء الطلاب في واجهة الحضور محصورة في `id, first_name, last_name` وبعد التحقق من الحلقة؛ الأدوار الحالية المخولة بالحضور تملك أصلًا `students.view` ضمن نطاقها.
