## إدارة قوائم الحلقات المنفذة

### ربط الطالب بالحلقة

- أداة عربية RTL وهاتف أولًا داخل صفحة الطلاب.
- تظهر فقط لمن يملك `students.manage` في فرع نشط.
- تعرض الطلاب النشطين في الفروع المسموح بها.
- تعرض الحلقات النشطة في مدرسة الطالب وفرعه فقط.
- تسمح بتعيين الحلقة أو إزالة التعيين وجعل `class_id = null`.
- UPDATE يرسل `class_id` فقط ولا يغير `school_id` أو `branch_id`.
- يعاد فحص الصلاحية والنطاق قبل الكتابة وتبقى RLS والقيود المركبة المرجع النهائي.

### تعيين المعلمين للحلقات

- أداة عربية RTL وهاتف أولًا داخل صفحة الحلقات.
- تظهر فقط لمن يملك `teachers.manage` في فرع نشط.
- تعرض المعلمين النشطين من فرع الحلقة فقط.
- تدعم `primary` و`assistant`.
- تعرض التعيينات النشطة وغير النشطة.
- تعيد تفعيل السجل السابق بدل إنشاء تعيين مكرر.
- تغير الدور عبر UPDATE للأعمدة القابلة للتعديل فقط.
- تلغي التعيين بتغيير `status` إلى `inactive` دون DELETE.
