## الصلاحيات والأمان

- فصل `memorization.view` عن `memorization.manage`.
- مستخدم العرض فقط لا يرى أدوات الإنشاء أو التعديل ولا يرسل طلبات كتابة.
- التحقق من الصلاحية قبل القراءة والكتابة.
- التحقق من الطالب النشط والمعلم المعيّن قبل الحفظ.
- حساب المعلم يرتبط بهوية المعلم المعيّنة له تلقائيًا.
- المعلم لا يستطيع اختيار معلم آخر أو تعديل سجل معلم آخر.
- مدير المدرسة يستطيع اختيار معلم نشط معيّن للحلقة.
- مدير الفرع يستطيع ذلك فقط داخل الفروع المعيّن مديرًا عليها، حتى عند امتلاكه دور معلم في فرع آخر.
- معلم السجل ثابت بعد الإنشاء ولا يمكن تغييره أثناء التعديل، توافقًا مع Migration 014.
- لا `select("*")`، ولا `service_role`، ولا `SUPABASE_SERVICE`، ولا `.delete()`.
- INSERT لا يرسل `school_id` أو `branch_id` أو `recorded_by` أو `last_modified_by`.
- UPDATE يرسل الأعمدة القابلة للتعديل فقط.
