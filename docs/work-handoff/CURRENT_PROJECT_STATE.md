1. تحميل سجل قائم بمعرف معلوم.
2. الضغط على `تعديل`.
3. ظهور شارة `وضع التعديل`.
4. الانتظار للتأكد أن effects لا تمسح `recordId`.
5. تغيير نهاية الآية.

7. تنفيذ UPDATE واحد دون INSERT.
