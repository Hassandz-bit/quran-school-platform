## نتائج التحقق الحي من Supabase

- الجداول موجودة: `attendance_sessions`, `attendance_records`, `attendance_record_history`.
- RLS مفعّل على الجداول الثلاثة.
- السياسات: SELECT وINSERT للجلسات؛ SELECT وINSERT وUPDATE للسجلات؛ SELECT فقط لسجل التدقيق.
- لا توجد سياسة أو منحة DELETE للمتصفح.
- `anon` لا يملك قراءة أو كتابة أو تنفيذ دالة نطاق الحضور.
- `authenticated` يملك SELECT، وINSERT/UPDATE على الأعمدة اللازمة فقط؛ لا منحة كتابة واسعة.
- `academic_supervisor` يملك `attendance.view` فقط ولا يملك `attendance.manage`.
- `school_admin` و`branch_manager` و`teacher` يملكون الإدارة ضمن نطاقهم؛ المعلم يتطلب ملفًا وتعيين حلقة نشطين.
- دوال الحضور الأمنية تضبط `search_path = ''`؛ دوال الـtrigger غير قابلة للتنفيذ من المتصفح.
- القيود المركبة ودالة التفويض تعزل المدرسة والفرع والحلقة.
- قيدا التفرد يمنعان تكرار الجلسة للحلقة/التاريخ وتكرار الطالب داخل الجلسة.
- لم تُكتب بيانات طلاب أو بيانات تجريبية أثناء التحقق.
