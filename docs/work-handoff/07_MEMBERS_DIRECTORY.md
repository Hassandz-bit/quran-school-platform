# 07 — دليل أعضاء المدرسة

- Issue: #33.
- Draft PR: #34.
- الفرع: `agent/members-directory`.
- Base SHA: `bdce2eebf758992aa043bd6411205fd5458a3d20`.

## النطاق

- مسار `/members` محمل كسولًا ومحمي بالجلسة والمدرسة والصلاحيات.
- صلاحية الدخول: `school_admin` أو `members.view` و`profiles.view` معًا.
- دليل قراءة فقط يستبعد العضويات revoked.
- يعرض الاسم والصورة وحالة Profile والعضوية والتواريخ والأدوار ونطاق كل دور وشارة العضو الحالي.
- يدعم الدور المدرسي والفرعي وتعدد الأدوار وتعدد فروع الدور نفسه وعضوًا بلا دور.
- فلاتر محلية للاسم والحالة والدور والفرع والأعضاء دون أدوار.
- رابط لوحة التحكم مشروط بنفس الصلاحيات.

## الأمان

- لا SQL ولا Migration 015.
- لا INSERT أو UPDATE أو UPSERT أو DELETE في طبقة الأعضاء.
- لا Admin API ولا دعوات ولا Auth users أو Profile أو Membership جديدة.
- كل قراءة tenant-owned مقيدة بـ`school_id` وتخضع لـRLS الحالية.
- لا UUID كامل ظاهر في الواجهة.

## المرحلة التالية

دعوات الموظفين وإدارة الأدوار بعد دمج واختبار هذا الـPR في مهمة منفصلة.
