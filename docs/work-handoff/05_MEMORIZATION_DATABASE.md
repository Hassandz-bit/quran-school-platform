# 05 — قاعدة بيانات متابعة الحفظ والمراجعة

## الهدف

إضافة سجل متابعة قرآنية آمن ومقيد بالمدرسة والفرع والحلقة، مع سجل تدقيق وعدم السماح بالحذف المباشر.

## الجداول

### `memorization_records`

يسجل:

- الطالب والحلقة والمعلم.
- تاريخ المتابعة.
- نوع الجلسة: حفظ جديد، مراجعة قريبة، مراجعة بعيدة، أو اختبار.
- رقم السورة وبداية ونهاية الآيات.
- تقييمًا من 1 إلى 5.
- عدد الأخطاء من 0 إلى 100.
- الملاحظات والواجب القادم.
- منشئ السجل وآخر معدل.

### `memorization_record_history`

- سجل append-only لكل إنشاء أو تعديل فعلي.
- يحتفظ بالقيم القديمة والجديدة ومن نفذ التغيير ووقته.
- لا توجد منح متصفح للإضافة أو التعديل أو الحذف.

## حدود السور والآيات

- الدالة `quran_surah_ayah_count(smallint)` تحتوي أعداد آيات السور الـ114.
- القيد يتحقق أن `ayah_start` و`ayah_end` ضمن العدد الفعلي للسورة.
- الاختبارات تتحقق من:
  - الفاتحة: 7.
  - البقرة: 286.
  - الكوثر: 3.
  - الناس: 6.
- لا يعتمد التصميم على الحد العام `1..286` وحده.
