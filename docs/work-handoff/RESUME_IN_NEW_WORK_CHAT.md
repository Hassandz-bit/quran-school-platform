## اختبار قبول الحضور

نُفّذ اختبار إنتاجي غير هدمي داخل Transaction ثم `ROLLBACK`:

- ربط طالب مؤقتًا بحلقة نشطة.
- إنشاء جلسة حضور وسجل حاضر.
- تعديل السجل إلى متأخر مع وقت وصول.
- التحقق من صف تدقيق للإنشاء وصف تدقيق للتعديل.
